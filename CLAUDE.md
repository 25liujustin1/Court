# Solomon's Court — project notes (earlier titles: Court, MADK)

A hidden-identity social deduction card game, inspired by the manga *MADK* (Ryo Suzuri). Players are demons with secret names; knowing a demon's name gives power over it. The noble ranks come from the Ars Goetia's hierarchy.

This repo holds the rework (masks, duels, souls as power; started 2026-11-15). The original game (`rules.md`, `playtest/`, `server/`, `sim/`, `playtests/`, `print/`, `name-table.tex`, and its design notes in the old CLAUDE.md) was removed from the repo on 2026-11-17. It is in git history (last commit containing it: `5abb644`) and copied to `C:\Users\LiuJu\court-old-game`. Its design decisions and rejected ideas are still worth checking before proposing a rule.

## Files

- `rules-rework.md` — the rulebook. **Source of truth.** Change rules here first. Rulings, open questions and known balance issues are at the bottom.
- `sim-rework/` — bots and balance simulation (`npm run sim`, see its README). Its own engine (`engine.js`), written from `rules-rework.md`.
- `rework-play/index.html` — play against the sim's bots in a browser (open the file directly). It loads `../sim-rework/engine.js` and `bots.js`, so keep those two browser-safe (no Node-only APIs at load). The engine reports public events through `g.on(type, data)` (`ev()` in engine.js; the sim never sets it); the page replays them as animations over snapshots of the table. When adding a rule action, emit an event for it. `npm run test:play` plays random games by clicking buttons and fails on any error. Art in `rework-play/art/` (icons CC BY 3.0 from game-icons.net, credited in the Rules pop-up; demon portraits public domain); sources in `rework-play/art/CREDITS.md`. Seat avatars are LPC pixel characters (Liberated Pixel Cup): `npm run build:lpc` regenerates `rework-play/art/lpc/parts/` and `art/lpc/CREDITS.md`; only layers offered under CC0, OGA-BY or CC-BY are used, so nothing is share-alike (check the license before adding a layer).
- Online: `npm start` (`rework-play/server.js`, port 3010, or `PORT`) serves the page and runs rooms (4-letter code, 3-6 seats, empty seats are bots). Deployed on Render from `main` (`render.yaml`; health check `/health`). The server holds the real game; every action is a command in `rework-play/net.js` (`runCommand`, also used by solo play through `doCmd()`), and each player gets a view with other players' secrets removed (`redact`; the page rebuilds a Game from it with `hydrate`). Off-turn decisions for people use `HumanBot` presets (enslave on a wrong naming, Ward automatically). Supporting a duel (called backing in the code) is asked of people for real: `withBacking` in `net.js` runs an engine step (a bot's turn, the end of a turn, a command) on a copy of the game, asks whoever could back a duel that came up, then runs the step on the real game with their answers (online the server waits up to `BACK_MS`, 15 s). This only works because the engine's randomness lives on the game (`g.rs`, read through `g.r()`): never use `Math.random` in the engine or bots. Player-to-player trades are offers the other player accepts; they lapse at the end of the offerer's turn. A player who drops out gets their turn played by a bot. Games live in memory only. `npm run test:online` plays games with 3 browsers and checks every message for leaked secrets. When adding an action: add it to `runCommand`, call it with `doCmd` in the page, and make sure `redact` hides any new secret field.

## Working rules

- When a rule changes: update `rules-rework.md`, then `sim-rework/engine.js` (and the page text in `rework-play/index.html` if it describes the rule), then run `npm test` and the sim.
- Keep the rulebook plain: short sections, little formatting. Justin prefers rule text he can paste.
- Don't re-propose ideas the original game rejected (see the old CLAUDE.md in the backup) without a new reason.
