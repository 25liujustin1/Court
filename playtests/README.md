# Playtest log

Record one row per game in `games.csv`, and short notes per game below. Change one rule at a time between games and write which variant you ran.

## What to record

- players, winner's role, how they won (naming, Rebellion, contract, devouring thralls)
- rounds played, round of the first elimination, round the bag first emptied
- naming attempts / successes / backfires
- dead turns (turns where a player did nothing meaningful)
- variant (rule changes being tested)

## After each game, ask everyone

1. When did you feel powerless or bored?
2. What did you want to do but couldn't?
3. Which role would you least like next time?
4. Did any rule need to be looked up or argued over?
