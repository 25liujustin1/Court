# Court

A hidden-identity card game about demons whose true names give power over them.

- Rules: `rules-rework.md`
- Play it: open `rework-play/index.html` in a browser (against bots), or run `npm start` and open http://localhost:3010 to play online
- Simulation: `npm run sim` (see `sim-rework/README.md`)
- Tests: `npm install`, then `npx playwright install chromium`, then `npm test`
- Design notes: `CLAUDE.md`
